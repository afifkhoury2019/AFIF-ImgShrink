    1AS USB Writer

    Write an ISO or disk image to a USB stick or SD card to make a bootable drive: Windows setup media, Linux installers, UEFI and ARM images.

    AS USB opens as its own window and asks for administrator rights, because it writes directly to the disk.

    Tip: shrunk images from the Shrink tab can be written straight to a card from the Disk Imager tab.

    Features

    • Bootable USB from Windows, Linux, UEFI and ARM images
    • ISO to USB for Windows 10 and 11 setup media
    • Partition scheme MBR or GPT, target system BIOS or UEFI
    • FAT32, NTFS, exFAT and UDF, chosen automatically from the image
    • Bad-block check, checksum verification and persistence support
    • Windows To Go, and downloadable official Windows images

    AS USB is part of AFIF ImgShrink. Its writing engine is built on Rufus 4.15 (GPLv3, © Akeo Consulting / Pete Batard) and is shipped unmodified except for its name and icon. Full source is included with the installer.
