AS USB — part of AFIF ImgShrink
===============================

AS USB is the bootable USB writer inside AFIF ImgShrink.

Its writing engine is a build of Rufus 4.15 (build 4.15.2396), renamed and
re-iconed only.

  Fork source      : https://github.com/afifkhoury2019/AFIF-USB

Modifications to the upstream engine, by Afif Khoury (2026):

  - application name, window captions, About and License dialog titles
  - VERSIONINFO product identity (product name, company, file names)
  - application and installer icons replaced
  - shader/UI strings unchanged otherwise

No functional changes were made to the USB writing, formatting, ISO handling
or boot code.
